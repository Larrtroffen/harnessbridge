# HarnessBridge v1.6.2 — 最新版本隔离测试（真实 DeepSeek）

**发布日期：** 2026-11-01
**产物：** `HarnessBridge-1.6.2-macos-arm64.dmg`、`.zip`、`SHA256SUMS.txt`

## 变更

这一版把之前最新 store 样本中的 mock 模型全部替换为**真实 DeepSeek API**。

- 在 SSH Home（Ubuntu 22.04 x86_64）隔离 `$HOME` 中安装缺失 Harness CLI，无 sudo；用 npm/GitHub/PyPI/官方安装器确认最新版本。
- 凡是支持**自定义 Base URL / OpenAI-compatible 端点**的 CLI，都配置为使用 **DeepSeek**（`https://api.deepseek.com/v1`，模型 `deepseek-flash`），不再用 mock。
- 生成并验证 4 个最新真实 store：
  - **Qwen Code 0.26.5** — `~/.qwen/projects/*/chats/*.jsonl`
  - **Goose 1.57.0** — `~/.local/share/goose/sessions/sessions.db`（SQLite+WAL）
  - **OpenCode 1.19.5** — `~/.local/share/opencode/opencode.db`（新版 SQLite v2 store；reader 已支持）
  - **iFlow CLI 0.5.19** — `~/.iflow/projects/*/session-*.jsonl`
- `samples/batch7/` 每个目录含 `SOURCE.md`（版本、DeepSeek 配置、许可、说明）；新增 `tests/test_latest_stores.py`；后端全量 **145 tests OK**。
- 更新 [docs/latest-version-matrix.md](https://github.com/Larrtroffen/harnessbridge/blob/main/docs/latest-version-matrix.md)：安装/最新版本、store 路径、登录/GUI 阻塞、诚实覆盖口径。
