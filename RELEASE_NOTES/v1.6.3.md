# HarnessBridge v1.6.3 — Intel Mac support

**Release date:** 2026-11-01
**Artifacts:** arm64 and x86_64 DMGs/ZIPs + `SHA256SUMS.txt`

## Highlights

- **Intel Mac (x86_64) build added** (issue #1):
  - `HarnessBridge-1.6.3-macos-x86_64.dmg` — x86_64 Swift app, x86_64 Python 3.12 runtime and cross-compiled x86_64 `zstd`.
  - `HarnessBridge-1.6.3-macos-arm64.dmg` — existing Apple Silicon build, rebuilt for 1.6.3.
  - The Intel build's app binary, embedded Python and zstd were verified as x86_64 Mach-O and the DMG/app signature verifies. It has **not been executed on an Intel Mac** by the maintainer (build host is Apple Silicon without Rosetta), so an Intel-Mac smoke test is requested from issue #1.
- `build.sh` now supports `--arch x86_64` / `--intel` and `--arch arm64` / `--arm`; SwiftPM scratch dirs are separated per architecture; Intel builds download the x86_64 Python runtime and cross-compile zstd 1.5.7.
- Homebrew cask uses `on_arm` / `on_intel` with the matching artifact and sha256.
- New doc: [docs/INTEL-MAC.md](https://github.com/Larrtroffen/harnessbridge/blob/main/docs/INTEL-MAC.md).

## Compatibility

- Minimum macOS: **13.0 Ventura** for both architectures (same app code; Intel hardware must support Ventura).
- Ad-hoc signed, not notarized: first launch may require right-click → Open on both architectures.
- Same backend/features on both builds: 43 source adapters, 32 native writers, coverage numbers unchanged (protocol 40/40, fixture-verified 35/40, real 22/40, REAL-EXAMPLE 2).

## Verification

- arm64: self-contained DMG; `--self-test` **31 PASS / 0 FAIL** on Apple Silicon.
- Intel: cross-compiled; `codesign --verify --deep --strict` passes; DMG mounts and contains an x86_64 app; app binary/Python/zstd `file` output all `x86_64`. Runtime self-test pending Intel hardware.
- Backend: 145 tests OK.
- Main CI: success (Ubuntu CLI/docs checks; macOS app build is manual because hosted macOS SDKs lag the macOS 26 API requirement).
