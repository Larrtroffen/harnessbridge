# HarnessBridge v1.5.2 — bug-fix release

**Release date:** 2026-10-31
**Artifacts:** `HarnessBridge-1.5.2-macos-arm64.dmg`, `HarnessBridge-1.5.2-macos-arm64.zip`, `SHA256SUMS.txt`
**License:** MIT · **Repo:** <https://github.com/Larrtroffen/harnessbridge>

## Fixes

- **Session detail expand/collapse** — “展开全文” now requests up to 2,000 characters instead of 400 (previously expanding often revealed no visible difference). The control is larger, has a chevron and a proper hit area; “收起” collapses it again.
- **Sidebar harness counts** — counts for each harness in the sidebar now refresh automatically after a migration/restore and whenever the app becomes active, instead of staying at the launch-time values.

No migration data formats or CLI contracts changed. The arm64 DMG remains self-contained (bundled Python, backend and zstd) and is ad-hoc signed; first launch may still require right-click → Open.

## Install

- Homebrew: `brew tap Larrtroffen/harnessbridge && brew trust Larrtroffen/harnessbridge && brew install --cask harnessbridge`
- Or download the DMG above and drag **HarnessBridge.app** to `/Applications`.
