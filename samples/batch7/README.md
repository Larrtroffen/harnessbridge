# Batch 7 — latest-version real stores (LOCAL-SMOKE)

These samples were produced by installing the **latest** harness versions in an isolated
`$HOME` on a remote Linux host (SSH Home) and running one trivial prompt against a local
mock OpenAI-compatible endpoint. They are **real tool/store formats**, but **not real user
conversations** and must not be counted as REAL coverage.

Included: Qwen Code 0.26.5, Goose 1.57.0, OpenCode 1.19.5. Each directory has its own
`SOURCE.md` with exact version, install/generation method, license and caveats.
