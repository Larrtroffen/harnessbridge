# HarnessBridge v1.7.0 — 英中双语本地化 + 官方 Logo

**发布日期：** 2026-11-01
**产物：** arm64 与 x86_64 DMG/ZIP + `SHA256SUMS.txt`

## 亮点

- **英语 + 简体中文本地化**：
  - `Localization/en.lproj/Localizable.strings`、`Localization/zh-Hans.lproj/Localizable.strings`。
  - **设置 → 界面语言** 支持 **跟随系统 / English / 简体中文**，切换即时生效（无需重启），并记住选择。
  - 静态 SwiftUI 文案、生成的状态/数量/后端提示均已本地化（例如 3 个会话 ↔ 3 sessions、重启提示、迁移向导步骤、迁移历史、会话详情）。
  - App 菜单命令与窗口标题跟随所选语言。
- **官方 Logo 刷新**：
  - 用官方组织资产替换 claude、codex、aider、devin 的旧第三方图。
  - 新增 amp、cherry-studio、claude-desktop、codebuff、droid、grok、hermes、iflow、openclaw、opencraw、trae、workbuddy、zcode 的 Logo。
  - 来源、许可/商标说明和 fallback 记录在 `tools/HarnessBridgeApp/Assets/Logos/SOURCE.md` 与 `UNRESOLVED.md`；`pi`、`mini-swe-agent`、`fx`、`oss`、`atif` 因没有可靠的官方产品 mark，保留首字母 fallback。
- 重新构建 **Intel (x86_64)** 与 **Apple Silicon (arm64)** 双架构便携版。

## 覆盖口径

- 后端/数据覆盖数字不变：协议 40/40、fixture-verified 35/40、真实用户会话 22/40、REAL-EXAMPLE 2。
- 本地化不改变任何转换语义。
