# HarnessBridge v1.6.1 — latest-version isolation test

**Release date:** 2026-11-01
**Artifacts:** `HarnessBridge-1.6.1-macos-arm64.dmg`, `.zip`, `SHA256SUMS.txt`

## What changed

- **Latest-version isolation test (SSH Home, Ubuntu 22.04 x86_64, no sudo):** installed missing harness CLIs in an isolated `$HOME` and confirmed latest versions against npm/GitHub/PyPI/official installers on 2026-11-01.
- **New current-store support:** OpenCode **1.19.5** moved its primary store to SQLite (`~/.local/share/opencode/opencode.db`, tables `session` / `message` / `part`); the reader now parses it natively while keeping legacy storage/v2 JSON fallbacks.
- **Validated latest on-disk stores** for **Qwen Code 0.26.5**, **Goose 1.57.0** and **OpenCode 1.19.5**, produced by latest binaries in an isolated HOME with a local mock model. These are **LOCAL-SMOKE** samples, not real user conversations.
- Added regression tests `tests/test_latest_stores.py`; full backend suite **144 tests OK**.
- Added [docs/latest-version-matrix.md](https://github.com/Larrtroffen/harnessbridge/blob/main/docs/latest-version-matrix.md): exact installed versions, latest-version sources, session-store paths, login/GUI blockers, and the honest coverage accounting.
- App/backend version **1.6.1**; self-contained arm64 DMG rebuilt.
