# Batch 7 — latest-version real stores, generated with DeepSeek

These samples were produced by installing the **latest** harness versions in an isolated
`$HOME` on a remote Linux host (SSH Home) and running one trivial prompt through each tool's
own **custom Base URL / OpenAI-compatible configuration**, pointed at the **real DeepSeek API**
(`deepseek-flash`). No mock model is used.

They are **real tool/store formats and real model responses**, but they are **not real user
conversations** and must not be counted as REAL user-session coverage. Evidence label:
**LOCAL-DEEPSEEK**.

Included: Qwen Code 0.26.5, Goose 1.57.0, OpenCode 1.19.5, iFlow CLI 0.5.19. Each directory has
its own `SOURCE.md` with exact version, install/generation method, license and caveats.
