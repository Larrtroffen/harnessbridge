# HarnessBridge v1.6.3 — 支持 Intel Mac

**发布日期：** 2026-11-01
**产物：** arm64 与 x86_64 DMG/ZIP + `SHA256SUMS.txt`

## 亮点

- **新增 Intel Mac（x86_64）构建**（issue #1）：
  - `HarnessBridge-1.6.3-macos-x86_64.dmg` —— x86_64 Swift 应用 + x86_64 Python 3.12 runtime + 交叉编译的 x86_64 `zstd`。
  - `HarnessBridge-1.6.3-macos-arm64.dmg` —— Apple Silicon 构建，同步更新到 1.6.3。
  - Intel 构建的 app、内嵌 Python、zstd 均已确认是 x86_64 Mach-O，DMG/app 签名校验通过；但维护者构建机是 Apple Silicon 且未安装 Rosetta，**尚未在真实 Intel Mac 上执行**，因此在 issue #1 请求 Intel 用户帮忙做一次 smoke test。
- `build.sh` 新增 `--arch x86_64` / `--intel` 与 `--arch arm64` / `--arm`；不同架构使用独立 SwiftPM 构建目录；Intel 构建自动下载 x86_64 Python 并交叉编译 zstd 1.5.7。
- Homebrew cask 使用 `on_arm` / `on_intel` 选择对应架构产物与 sha256。
- 新增文档：[docs/INTEL-MAC.md](https://github.com/Larrtroffen/harnessbridge/blob/main/docs/INTEL-MAC.md)。

## 兼容性

- 最低 macOS：两个架构均为 **13.0 Ventura**（同一套代码；Intel 机器需支持 Ventura）。
- ad-hoc 签名、未公证；两种架构首次启动都可能需要右键 → 打开。
- 两个架构共享同一 backend/功能：43 source adapters、32 native writers，覆盖数字不变（协议 40/40、fixture-verified 35/40、真实 22/40、REAL-EXAMPLE 2）。

## 验证

- arm64：自包含 DMG；Apple Silicon 上 `--self-test` **31 PASS / 0 FAIL**。
- Intel：交叉编译完成；`codesign --verify --deep --strict` 通过；DMG 可挂载且内含 x86_64 app；app/Python/zstd 的 `file` 输出均为 x86_64。运行时 self-test 待 Intel 硬件。
- 后端：145 tests OK。
- main CI：success（Ubuntu CLI/docs 检查；macOS 应用构建仍是手动，因为 hosted macOS SDK 落后于 macOS 26 API 要求）。
