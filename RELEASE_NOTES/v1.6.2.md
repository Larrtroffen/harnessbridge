# HarnessBridge v1.6.2 — latest-version isolation test with DeepSeek

**Release date:** 2026-11-01
**Artifacts:** `HarnessBridge-1.6.2-macos-arm64.dmg`, `.zip`, `SHA256SUMS.txt`

## What changed

This release replaces the earlier mock-model latest-store samples with **real DeepSeek API** runs.

- Installed the missing harness CLIs in an isolated `$HOME` on SSH Home (Ubuntu 22.04 x86_64, no sudo) and confirmed latest versions against npm/GitHub/PyPI/official installers.
- For every installable CLI that allows a **custom Base URL / OpenAI-compatible endpoint**, configured it to use **DeepSeek** (`https://api.deepseek.com/v1`, model `deepseek-flash`) instead of a mock.
- Generated and validated **real latest stores** for:
  - **Qwen Code 0.26.5** — `~/.qwen/projects/*/chats/*.jsonl`
  - **Goose 1.57.0** — `~/.local/share/goose/sessions/sessions.db` (SQLite+WAL)
  - **OpenCode 1.19.5** — `~/.local/share/opencode/opencode.db` (new SQLite v2 store; reader added)
  - **iFlow CLI 0.5.19** — `~/.iflow/projects/*/session-*.jsonl`
- New fixtures in `samples/batch7/`, each with `SOURCE.md` (version, DeepSeek config, license, caveats); regression tests `tests/test_latest_stores.py`; backend suite **145 tests OK**.
- Updated [docs/latest-version-matrix.md](https://github.com/Larrtroffen/harnessbridge/blob/main/docs/latest-version-matrix.md) with installed/latest versions, store paths, login/GUI blockers, and the no-inflation accounting.
