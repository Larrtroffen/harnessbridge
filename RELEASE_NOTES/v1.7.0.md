# HarnessBridge v1.7.0 — English/Chinese localization + official logos

**Release date:** 2026-11-01
**Artifacts:** arm64 and x86_64 DMGs/ZIPs + `SHA256SUMS.txt`

## Highlights

- **English + Simplified Chinese localization**:
  - `Localization/en.lproj/Localizable.strings` and `Localization/zh-Hans.lproj/Localizable.strings`.
  - **Settings → Interface Language** supports **Follow System / English / 简体中文** and switches live (no restart needed); the choice is persisted.
  - Static SwiftUI labels plus generated status/count/backend hints are localized (examples: 3 个会话 ↔ 3 sessions, 重启后可见 hints, wizard steps, migration history, session detail).
  - App menu commands and window title follow the selected language.
- **Official logo refresh**:
  - Replaced third-party/old images for claude, codex, aider and devin with official organization assets.
  - Added logos for amp, cherry-studio, claude-desktop, codebuff, droid, grok, hermes, iflow, openclaw, opencraw, trae, workbuddy, zcode.
  - Sources, licenses/trademark notes and fallbacks are listed in `tools/HarnessBridgeApp/Assets/Logos/SOURCE.md` and `UNRESOLVED.md`; `pi`, `mini-swe-agent`, `fx`, `oss`, `atif` intentionally use letter fallback where no honest product mark exists.
- Both **Intel (x86_64)** and **Apple Silicon (arm64)** portable builds are rebuilt.

## Coverage/accounting

- Backend/data coverage numbers are unchanged: protocol 40/40, fixture-verified 35/40, real user sessions 22/40, REAL-EXAMPLE 2.
- The localization work does not alter conversion semantics.

## Verification

- App self-test: **31 PASS / 0 FAIL** on Apple Silicon.
- Live language switch verified via the actual Settings picker (English ↔ 简体中文) and persisted across relaunch.
- Backend: **145 tests OK**.
- Main CI: success.

## Known limits

- Some dynamic backend strings that have no app-side source translation may remain in Chinese until the backend provides i18n metadata.
- Logos for products without a public product-specific mark use fallback letters rather than misleading parent/personal images; see `UNRESOLVED.md`.
