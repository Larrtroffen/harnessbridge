## 亮点

- **43 个 source adapter**：40 个 canonical Harness 格式，另加 bonus **iFlow**、**Zed** reader；**32 个原生 writer 目标**。
- **批 6 外部 fixture 矩阵**（`asi matrix-batch6`）：
  - readers：40 canonical 标签中 **34 pass / 6 partial / 0 fail**；
  - writers：**32/32 pass**（staging 写入 + 读回校验）；
  - **fixture-verified 格式覆盖：35/40**（partial 计入，CONSTRUCTED 不计）；
  - **真实会话覆盖：22/40**（新增 Continue 的真实 Apache-2.0 样本）；
  - **REAL-EXAMPLE：2**（Harbor 的 openhands / mini-swe-agent 公开真实轨迹，单列）。
- **新增原生 reader**：WorkBuddy、Windsurf、TRAE（原生 CLI + codeg ACP 兜底）、ZCode、Cherry Studio、Claude Desktop / Cowork、OpenCraw。

## 不做夸大的部分

- **35/40 fixture-verified ≠ 35/40 真实用户会话**；真实会话覆盖为 **22/40**，fixture/constructed 证据分开报告。
- 6 个 canonical 标签为 **partial**（codex、cline、fx、kilo-code、roo、openhands，ATIF round-trip 有损差异），不算完全 pass。
- 本机未安装的 Harness 无法做 L3 原生加载验证；L3 需要目标工具安装后实测。
- 不 vendor Crush（FSL）、Zed（NOASSERTION/GPL 混合）fixture；必要时 reader-only。
- ad-hoc 签名、未公证；首次打开可能需右键「打开」。

## 安装

- Homebrew：`brew tap Larrtroffen/harnessbridge && brew trust Larrtroffen/harnessbridge && brew install --cask harnessbridge`
- 或下载上方 DMG，把 **HarnessBridge.app** 拖进 `/Applications`。
