# HarnessBridge v1.5.2 — 缺陷修复版

**发布日期：** 2026-10-31
**产物：** `HarnessBridge-1.5.2-macos-arm64.dmg`、`HarnessBridge-1.5.2-macos-arm64.zip`、`SHA256SUMS.txt`
**许可证：** MIT · **仓库：** <https://github.com/Larrtroffen/harnessbridge>

## 修复

- **会话详情展开/收起**：「展开全文」现在最多请求 2,000 字符（旧版后端 text-limit 为 400，展开后常常看不出变化）；按钮已加大、带箭头，命中区域更合理，「收起」可以正常折回。
- **侧边栏 Harness 会话数**：迁移/恢复完成以及 App 重新激活时会自动重新检测刷新，不再停留在启动时的旧数字。

迁移数据格式与 CLI 契约未改变。arm64 DMG 仍为独立包（内嵌 Python、后端与 zstd），ad-hoc 签名；首次打开可能仍需右键「打开」。

## 安装

- Homebrew：`brew tap Larrtroffen/harnessbridge && brew trust Larrtroffen/harnessbridge && brew install --cask harnessbridge`
- 或下载上方 DMG，把 **HarnessBridge.app** 拖进 `/Applications`。
