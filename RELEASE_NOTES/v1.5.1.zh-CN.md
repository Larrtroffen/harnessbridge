# HarnessBridge v1.5.1 — 首次公开版本（独立可运行）

**发布日期：** 2026-10-31
**产物：** `HarnessBridge-1.5.1-macos-arm64.dmg`、`HarnessBridge-1.5.1-macos-arm64.zip`、`SHA256SUMS.txt`
**许可证：** MIT · **仓库：** <https://github.com/Larrtroffen/harnessbridge>

## 简介

HarnessBridge 用于在 Claude Code、Codex、DeepSeek Harness、OMP、Qoder、Pi、Gemini CLI 等 **40+ 种 AI Agent Harness** 之间迁移会话。它由原生 SwiftUI macOS App 与 `asi` CLI 组成，转换/迁移逻辑统一由 CLI 提供。

v1.5.1 是 **首个公开 GitHub 版本**：新名称、玻璃质感原生界面，以及 **自带运行时的 Apple 芯片独立应用**。

## 亮点

- **改名不改使命：** `HarnessBridge.app`，bundle id `io.github.larrtroffen.harnessbridge`；CLI 仍为 `asi`。
- **Liquid Glass 界面**（macOS 26+；macOS 13–25 自动回退到材质/NSVisualEffectView；尊重减少动态效果/减少透明度）。
- **独立 arm64 DMG**：内嵌 Python 3.12、`asi` 后端与 `zstd`；**无需安装 Python/zstd，也无需 clone 仓库**。注意：ad-hoc 签名、未做 Apple 公证。
- **默认直接写入目标 Harness 会话库**：DSH / Claude Code / OMP 稳定；Codex / Qoder / Pi / Gemini 实验性；Goose 仅导出。
- **保留或移出原始会话，且可恢复**：移出仅在目标安装+校验成功后把源文件改名为 `*.migrated-<时间>.bak`，永不删除；`migrate-restore`/App 可恢复。
- **一键全量迁移**：其他所有已检测 Harness → 指定目标；支持条数/最近天数、dry-run 计划、重复跳过、覆盖备份、进度、取消、逐条结果与原子增量 journal。
- **更安全的写入**：staging + 原子 rename、安装后校验、失败回滚、`--dry-run` 零写入、真实写入必须 `--yes`。
- **纯本地**：无网络、无遥测、无账号。

## 安装

1. 从 Release 下载 `HarnessBridge-1.5.1-macos-arm64.dmg`（或 `.zip`）。
2. 校验：`shasum -a 256 -c SHA256SUMS.txt`。
3. 打开 DMG，把 **HarnessBridge.app** 拖进 `/Applications`。
4. 首次启动（ad-hoc 签名）：右键 → **打开**，或 `xattr -dr com.apple.quarantine /Applications/HarnessBridge.app`。
5. 可选源码构建：
   ```bash
   git clone https://github.com/Larrtroffen/harnessbridge.git
   cd harnessbridge/tools/HarnessBridgeApp
   swift build -c release && ./build.sh && open dist/HarnessBridge.app
   ```
   `./build.sh` 默认便携构建（下载固定版本 Python 到 `vendor/`）；`./build.sh --dev` 使用仓库内后端。

- **后端：** 本地 **81 个单测全绿**（隔离 HOME/env；依赖本机 Harness 数据的测试不在 hosted CI 运行）；App 内已内置 coverage 产物。

## 已知限制

- ad-hoc 签名、未公证；首次打开需右键「打开」。
- Codex/Qoder/Pi/Gemini 直装为实验性（目标工具可能需要重启/重建索引）。
- 目录/多文件型会话源不支持移出（会明确提示并保留源）。
- Token 仅当来源记录时显示。
