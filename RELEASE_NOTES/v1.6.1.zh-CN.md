# HarnessBridge v1.6.1 — 最新版本隔离测试

**发布日期：** 2026-11-01
**产物：** `HarnessBridge-1.6.1-macos-arm64.dmg`、`.zip`、`SHA256SUMS.txt`

## 变更

- **最新版本隔离测试（SSH Home，Ubuntu 22.04 x86_64，无 sudo）**：在隔离 `$HOME` 中安装缺失 Harness CLI，并于 2026-11-01 用 npm/GitHub/PyPI/官方安装器核对最新版本。
- **当前 store 支持**：OpenCode **1.19.5** 主 store 迁移到 SQLite（`~/.local/share/opencode/opencode.db`，`session`/`message`/`part` 表）；reader 已原生解析，同时保留 legacy storage/v2 JSON 兜底。
- **验证最新磁盘格式**：Qwen Code 0.26.5、Goose 1.57.0、OpenCode 1.19.5 用最新二进制 + 本地 mock 模型生成；均为 **LOCAL-SMOKE**，不是真实用户会话。
- 新增 `tests/test_latest_stores.py`；后端全量 **144 tests OK**。
- 新增 [docs/latest-version-matrix.md](https://github.com/Larrtroffen/harnessbridge/blob/main/docs/latest-version-matrix.md)：安装版本、最新版本来源、store 路径、登录/GUI 阻塞、诚实覆盖口径。
- App/后端版本 **1.6.1**，重建 arm64 DMG。

## 不做夸大

- 需要登录的 CLI（Copilot/Gemini/Kimi/Junie/Kiro/TRAE/Droid/Amp/CodeBuddy/WorkBuddy）无凭据无法生成真实对话。
- 官方 Grok Build 安装器（x.ai）在当前网络不可达；Codebuff 运行时下载、OpenHands 最新 CLI entry point 受阻。
- 纯桌面端 Harness（ZCode 3.16.3、Windsurf、Cherry Studio、Claude Desktop、Zed、OpenCraw）当前无公开 headless CLI。
